# Project Rules and Constraints

- **STRICT ENFORCEMENT**: If the user explicitly states "KEINE EDITS" (no edits) or clearly asks for an analysis/explanation only, you are FORBIDDEN from using any code modification tools (edit_file, multi_edit_file, create_file, etc.).
- **ASK FOR PERMISSION**: In cases where you think a change is needed but the user has previously expressed frustration about unsolicited edits, you MUST explain the issue first and ask: "Would you like me to implement these changes for you?" before proceeding.
- **RESPECT COMMANDS**: When the user says "ANTWORTE" (answer), prioritize the verbal explanation over action.
